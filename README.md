# Sinegor — Анализатор-217

Сервис сопровождения заказов на исследование юридических материалов и техническую подготовку документов.

Реализованы B1–B5: FastAPI backend с PostgreSQL, Alembic, авторизацией, карточками заказчиков, заказами, ручной оплатой и журналом событий. Работают обмен PDF-соглашениями, проверка администратором, закрытое хранение и автоматические переходы заказов. Frontend и CMS пока представлены каркасом. Исходная документация сохранена в `docs/`.

## Структура

```text
apps/
  web/                    React + TypeScript, React Router Framework Mode / SSR
  api/                    Единый модульный FastAPI backend
    src/sinegor/
      api/                HTTP-маршруты и зависимости доступа
      core/               Конфигурация, безопасность, логирование
      db/                 SQLAlchemy, подключения и транзакции
      modules/            Бизнес-модули
      integrations/       Серверные адаптеры внешних сервисов
      jobs/               Команды периодических задач
    migrations/           Миграции Alembic
    tests/                Доменные, интеграционные и security-проверки
  cms/                    Strapi 5, только публичный контент
contracts/openapi/        Контракт FastAPI для генерации клиента TypeScript
infra/                    Docker Compose, Caddy, PostgreSQL, scheduler
scripts/                  Проверки, резервирование и восстановление
tests/                   Сквозные сценарии Playwright
```

## Архитектурные ограничения

- Заказы, клиенты, соглашения и права обслуживает только FastAPI.
- Сайт передаёт материалы через ссылку на Яндекс Диск; загрузки и управления правами через сайт нет.
- Соглашения хранятся в закрытом томе, отдельно от удаляемой папки заказа.
- Заказ закрывается через 14 календарных дней после готовности и отправки уведомления. Удаление — отдельная операция с подтверждением администратора.
- После удаления сохраняются подписанное соглашение и журнал событий.
- Strapi управляет только публичными страницами и медиа.
