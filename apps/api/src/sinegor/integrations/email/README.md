# Исходящая почта

B3: `SMTPAuthMailer` через SMTP_SSL Яндекс 360 отправляет приглашения и Magic Link; интерфейс AuthMailer подменяется в тестах. Пароль приложения и отправитель задаются через настройки. Содержимое писем и адреса не выводятся в логи.

Остальные типы сообщений, гарантированная доставка и проверка реального SMTP относятся к B7. В тестах реальные письма не отправляются.
