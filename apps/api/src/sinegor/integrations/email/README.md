# Исходящая почта

`SMTPAuthMailer` отправляет приглашения, Magic Link, сообщения по соглашению и готовности результата. Учётная запись, пароль приложения и отправитель задаются в Settings: TLS с начала соединения при `SMTP_USE_SSL=true`, иначе обязательный STARTTLS до входа. Адаптер не привязан к личной или корпоративной почте.

Сохраняемая PostgreSQL-очередь и `process_notifications` повторяют ошибки. Принятие SMTP не доказывает доставку/прочтение; при потере подтверждения возможен дубликат. Адреса, содержимое писем и ссылки входа не логируются. Настройки, ответы API и восстановление — в [эксплуатации уведомлений](../../../../../../docs/notifications.md).

В pytest транспорт подменяется, в [живом E2E](../../../../../../tests/e2e/README.md) настоящий адаптер общается с локальным TLS SMTP fixture. Реальная почтовая доставка проверяется отдельно на выделенном тестовом получателе.
