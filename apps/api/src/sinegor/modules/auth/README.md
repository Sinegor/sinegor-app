# Auth — B3

Реализованы схемы входных данных, одноразовые ссылки, отправка приглашений, серверные сессии, вход администратора Argon2id/TOTP, CSRF и ограничения попыток в PostgreSQL. Зависимости доступа: Authenticated, Admin, Customer, OwnedOrder.

Настройка, первый администратор и HTTP-контракт: `docs/authentication.md` от корня проекта. Пароли/токены/ключи не логировать; для будущих административных маршрутов использовать Admin, для клиентских заказов — OwnedOrder.
