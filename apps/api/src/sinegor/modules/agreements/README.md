# agreements

Обмен подписанными PDF, проверка, отклонение и подтверждение; удаление первоначального файла только после подтверждения окончательного. Утверждённый PDF и его хеш сохраняются.

Реализованы административные и клиентские HTTP-маршруты, проверка PDF/размера, версии для защиты от устаревшего решения, закрытое хранилище и журналирование. Утверждение переводит заказ в ожидание материалов той же транзакцией. Устаревшие файлы удаляются после commit; очередь и CLI cleanup_agreements обеспечивают повтор после ошибки и очистку потерянных объектов. Контракт: `docs/agreements.md` от корня репозитория.
