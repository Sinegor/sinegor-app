# retention

14-дневный срок после готовности и отправки уведомления; независимое автоматическое закрытие заказа; запросы удаления, досрочное разрешение, отсрочка и подтверждение администратора.

Реализован в B8. `process_orders` создаёт ожидающие запросы и возвращает истёкшие отсрочки на рассмотрение; удаления не выполняет. Решение администратора, операция Диска B6 и завершение заказа разделены. HTTP-контракт и эксплуатация — [docs/retention.md](../../../../../../docs/retention.md).
