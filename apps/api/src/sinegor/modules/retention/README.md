# retention

14-дневный срок после готовности и отправки уведомления; независимое автоматическое закрытие заказа; запросы удаления, досрочное разрешение, отсрочка и подтверждение администратора.

HTTP-обработчики делегируют операции сервису модуля; изменения и события выполняются в согласованных транзакциях. Реализация добавляется следующим этапом.
