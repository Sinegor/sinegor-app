# orders

Два вида услуг, жизненный цикл заказа, ручная оплата и отметка MaterialHandover. Статусы: ожидает оформления, ожидает материалы, в работе, результат готов, завершён, отменён.

HTTP-обработчики делегируют операции сервису модуля; изменения и события выполняются в согласованных транзакциях. Реализация добавляется следующим этапом.
