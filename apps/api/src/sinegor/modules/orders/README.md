# orders

Два вида услуг, жизненный цикл заказа, ручная оплата и отметка MaterialHandover. Статусы: ожидает оформления, ожидает материалы, в работе, результат готов, завершён, отменён.

Реализованы HTTP API, блокировки переходов, проверки соглашений, уведомление о готовности через SMTP и идемпотентная оплата. `service.process_lifecycle` переводит утверждённые заказы в ожидание материалов и завершает готовые через 14 дней; CLI: `python -m sinegor.jobs.process_orders`. Контракт: [заказы](../../../../../../docs/orders.md).
