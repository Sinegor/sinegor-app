# disk

Связь заказа с папкой 1:1, создание, привязка, ссылка и подтверждаемое удаление. Без загрузки материалов, списка файлов и управления правами.

Реализован в B6. Сервис проверяет путь и идентичность папки, сохраняет намерение и асинхронную операцию удаления, журналирует результат. Подтверждение запроса удаления относится к B8. Настройки, HTTP-контракт и восстановление — [docs/disk.md](../../../../../../docs/disk.md).
