# notifications

Приглашения, Magic Link, готовность по email; консультации и сроки удаления через Telegram. Не создавать CRM заявок. Фиксировать передачу письма SMTP отдельно от факта прочтения.

Реализован в B7: очередь PostgreSQL, быстрая попытка после HTTP и отдельный `process_notifications` для повторов и напоминаний. Ошибки не содержат адресов и секретов; контактные поля завершённых заданий очищаются. Настройки каналов, ответы API и расписание — [docs/notifications.md](../../../../../../docs/notifications.md).
