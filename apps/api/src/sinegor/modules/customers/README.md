# customers

Карточки заказчиков, нормализованный уникальный email и история заказов.

Администратор создаёт, просматривает и изменяет карточки. Создание и изменение журналируются в CustomerEvent одной транзакцией с карточкой; смена email отзывает ссылки и сессии. История заказов доступна через фильтр customer_id в административном API заказов. Контракт: `docs/orders.md` от корня репозитория.
