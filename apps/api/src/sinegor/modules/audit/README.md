# audit

Реализованы `OrderEvent` и `CustomerEvent`: служебные факты заказа и изменения карточки без содержимого документов, копий персональных данных и секретов. События добавляют сервисы соответствующих модулей в одной транзакции с изменением данных.

Журнал заказа читается через авторизованные маршруты с проверкой роли и принадлежности. Подписанный PDF и события сохраняются после завершения заказа и удаления папки материалов. Модель и ограничения — в [модели данных](../../../../../../docs/data-model.md), операции — в [контракте заказов](../../../../../../docs/orders.md).
