# Backend-проверки

B1–B3: `unit/` содержит проверки конфигурации, ошибок, логов и жизненного цикла сессии; `integration/` — реальные PostgreSQL readiness, request session, цикл миграций Alembic и ограничения всех 11 сущностей (test_models.py).

Из `apps/api`: `uv run --locked pytest`. Без TEST_DATABASE_URL интеграционные проверки пропускаются. Используйте пустую выделенную БД с именем, оканчивающимся на `_test`: миграционный тест откатывает схему до base. Подробные команды — в README приложения.

Будущие этапы добавляют доменные и security-тесты: переходы статусов, сроки, соглашения, IDOR, Magic Link, CSRF и подтверждение удаления. Реальные клиентские материалы не использовать.

B3: `test_auth.py` проверяет HTTP-сценарии и права, `test_auth_concurrency.py` использует независимые PostgreSQL-соединения для конкурентного погашения ссылок и TOTP. Unit-тесты проверяют Argon2id, подпись CSRF, конфигурацию и SMTP_SSL с подменой транспорта.
