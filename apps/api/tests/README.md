# Backend-проверки B1–B8

`unit/` проверяет настройки, ошибки, безопасные логи, lifecycle сессий, Argon2id/CSRF, ограниченное PDF-хранилище и адаптеры SMTP, Telegram и Яндекс Диска с подменой транспорта.

`integration/` использует настоящую PostgreSQL: readiness, миграции upgrade/downgrade/check, ограничения моделей, авторизацию/IDOR, переходы заказов, PDF-обмен, привязки и удаление папок, очередь уведомлений, досрочное разрешение, отсрочки и подтверждение удаления. Конкурентные сценарии используют независимые соединения; проверяются повторные действия и откат событий вместе с изменениями.

Из `apps/api`:

```bash
uv run --locked pytest -m "not integration"
TEST_DATABASE_URL=postgresql+psycopg://test_user:test_password@127.0.0.1:5432/sinegor_test uv run --locked pytest
```

Второй URL — пример: создайте отдельную пустую БД с именем, оканчивающимся на `_test`, и тестовую роль с собственным паролем. Без TEST_DATABASE_URL интеграционные проверки пропускаются. Миграционные тесты откатывают схему до base; рабочая `sinegor` для них недопустима. Production-проверки запрещают стандартный dev-пароль `sinegor_dev`.

Фикстуры подставляют тестовый URL в DATABASE_URL только внутри тестов и отключают рабочий dotenv. Рабочий `.env` не изменяется. Подробная настройка — в [README API](../README.md).

Отдельные процессы проверяют создание администратора, `purge_auth` и обработчик заказов. Регрессия `test_purge_auth_cli.py` проверяет самостоятельный запуск без импортов приложения, очистку только истёкшей авторизации, сохранность действующих и бизнес-записей, повторный запуск.

Внешние сервисы в pytest заменены адаптерами; реальная доставка и операции Диска проверяются отдельно на выделенных получателях и синтетических материалах. Постоянный [живой E2E-контур](../../../tests/e2e/README.md) поднимает реальные приложения без подмены их HTTP API и проверяет адаптеры через локальные SMTP/HTTPS fixtures. UI Playwright с перехватом внутренних API находится отдельно в `apps/web/tests/browser`. Реальные клиентские материалы не использовать.
