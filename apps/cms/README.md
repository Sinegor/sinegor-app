# CMS

Место для Strapi 5 Community Edition. Только публичные данные: услуги, страницы, публикации, контакты, видеопрезентация и SEO.

- `src/api/` — будущие content types и их контроллеры.
- `src/components/` — повторно используемые компоненты контента.
- `config/` — сервер, отдельная БД, настройки медиа и доступа.
- `public/` — публичные ресурсы CMS; uploads в отдельном томе.

Следующий шаг: инициализировать Strapi, зафиксировать зависимости, создать модели контента. Публичное чтение разрешать только для опубликованных материалов. CMS Admin защитить; не открывать его через публичный reverse proxy по умолчанию. Клиенты, заказы и соглашения в CMS не хранятся.
