# SINEGOR LAB — передача отчётных документов на локальный хост

Дата: 17.11.2026, Europe/Moscow.

По уточнению владельца в AGENTS.md на VPS дополнен раздел Task Reports: отчёты и сопровождающие материалы выполнения заданий без секретов передаются на локальную Fedora в /home/sinegor/documents/IT/Pet_project/sinegor-app/docs/reports/. Итоговые ответы должны содержать ссылки на фактически переданные локальные файлы. Серверные копии могут сохраняться.

Это исключение для отчётных документов. Изменения исходного кода, рабочих конфигураций и служебных скриптов по-прежнему выполняются непосредственно на VPS.

В комплект передачи включены:

- agent-source-and-git-rules-2026-11-17.md — отчёт о постоянных правилах Git и серверной разработке.
- production-layout-category-b-result-2026-11-17.md — отчёт о пяти файлах категории B.
- production-layout-category-b-evidence-2026-11-17.json — результаты ограниченных проверок категории B.
- agent-reports-local-delivery-2026-11-17.md — настоящее уточнение порядка передачи.

Для передачи используются только перечисленные отчётные файлы; рабочие private-конфигурации, env, ключи и архивы не передаются. Целостность каждой локальной копии проверяется по SHA256 серверного документа. HEAD и Git index при изменении инструкции сохранены; сервисы не затрагиваются. Второе задание по production layout не выполняется.
