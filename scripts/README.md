# Служебные команды

`check_structure.py` проверяет наличие каталогов, документов каркаса и шаблонов окружения приложений без внешних зависимостей. Шаблоны находятся в `apps/api`, `apps/web` и `apps/cms`; корневой `.env.example` не предусмотрен. Полный перечень — в [карте реализации](../docs/project-structure.md#файлы-окружения).

Из корня: `python3 scripts/check_structure.py`. Проверка наличия структуры не подтверждает реализацию production-конфигураций в зарезервированных каталогах.

`export_openapi.py` экспортирует реальную схему FastAPI в `contracts/openapi/api.json` без соединения с БД и чтения dotenv. Запуск: `apps/api/.venv/bin/python scripts/export_openapi.py`. Команда перезаписывает генерируемый контракт; далее из `apps/web` выполните `npm run api:generate`. См. [контракт](../contracts/openapi/README.md).

`init-cms-db.sh` явно создаёт отсутствующие CMS-БД/роль в указанном контейнере проекта. Требует переменную `CMS_DATABASE_PASSWORD`; не меняет существующий пароль. Порядок использования — в [README CMS](../apps/cms/README.md).

`backup/backup.py` — ручные команды pg_dump/Restic и восстановления обеих БД, связанных PDF соглашений и локальных CMS-медиа в отдельное тестовое окружение. Конфигурация, ограничения согласованности и проверки — в [инструкции резервирования](backup/README.md). Материалы заказов с Яндекс Диска в набор не входят; архивы и секреты хранятся вне репозитория. Производственное расписание и политика хранения относятся к T2.

Автоматизация проверки приложений находится в [tests/e2e](../tests/e2e/README.md).

## Исходник Certbot hook

`deployment/deploy-tls.py` — версия исходника действующего `/usr/local/sbin/sinegor-lab-prod-deploy-tls`. При переносе категории B системная копия не заменяется; файл не запускается для синтаксической проверки. Пути production и состояние перехода описаны в [infra/README.md](../infra/README.md).
