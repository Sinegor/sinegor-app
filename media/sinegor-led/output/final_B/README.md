# SINEGOR LAB — финальный вариант B

Готовые последовательности: **2048 × 720, PNG RGBA 8 бит, 25 FPS**.

- `intro/intro_0001.png` … `intro_0050.png` — включение, 2 секунды.
- `loop/loop_0001.png` … `loop_0750.png` — бесшовный цикл, 30 секунд.
- `SINEGOR_LAB.blend` — две редактируемые сцены, Manrope SemiBold упакован.
- `srgb.ocio` — цветовой профиль для воспроизводимого открытия .blend.
- `scene_config.json` — фактические параметры B; ореол ±4%.
- `export_checks.json` и `png_sha256.json` — контроль всех 800 PNG и их SHA-256.
- `FINAL_REPORT.md` — результаты и ограничения проверок.

В Shotcut сначала установите проект 25 FPS. Откройте первый PNG каждой папки,
включите Properties → Image sequence, один PNG на кадр. Длительности — 2 и 30 секунд.
Разместите включение и цикл вплотную на дорожке над видео; повторы цикла также
располагайте вплотную, без переходов и изменения скорости. Chroma Key не нужен.
Не добавляйте кадр 751 и не дублируйте завершающий кадр.

Открытие .blend из этой папки в обычной установке Blender 5.1.1:

```bash
OCIO="$PWD/srgb.ocio" blender SINEGOR_LAB.blend
```

Для установленного Linux Flatpak:

```bash
flatpak run "--env=OCIO=$PWD/srgb.ocio" org.blender.Blender "$PWD/SINEGOR_LAB.blend"
```

`checks/loop_twice_graphite.mkv` — отдельная **непрозрачная** диагностическая
композиция на имитации графита, не материал для наложения. Два цикла проверены
через движок установленного Shotcut/MLT; исходный проект Shotcut не менялся,
GUI-просмотр на исходном видео не выполнялся.

Генератор, исходные параметры, пресеты и полная инструкция сохранены в
`../../generate.py`, `../../config.json`, `../../glow_presets.json`, `../../README.md`.
