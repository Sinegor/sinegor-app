# Финальный экспорт SINEGOR LAB — B

Вариант B выбран пользователем после сравнения A/B/C. Полный экспорт выполнен
Blender **5.1.1**, Cycles CPU, 32 samples; рендер завершился с кодом 0.
Результат сохранён в новую папку `media/sinegor-led/output/final_B`, прежние
сцены и превью не перезаписывались. Видео и проект Shotcut не изменены.

## Поставка

- 50 PNG RGBA: `intro/intro_0001.png` … `intro_0050.png`, 2 секунды.
- 750 PNG RGBA: `loop/loop_0001.png` … `loop_0750.png`, 30 секунд.
- Все кадры — 2048 × 720, 8 бит на канал; частота в сценах и тесте — 25 FPS.
- `SINEGOR_LAB.blend`: редактируемые сцены включения и цикла, Manrope SemiBold упакован.
- `srgb.ocio`, `OFL.txt`, `scene_config.json`, инструкции и отчёты проверок.

Параметры B сохранены: near 26 px / 0.90, far 90 px / 0.50,
интенсивность 1.0, пульсация ±4%. Геометрия, фаска, исправление A, камера,
брендовые цвета `#F1F4F2` и `#9DE0C4` не менялись.

## Проверки всех PNG

`verify_export.py` проверил все **800 файлов**. Точная нумерация подтверждена:
пропусков и постороннего хвоста нет. Проверены RGBA/размер, полностью прозрачный
периметр каждого кадра и отсутствие изображения в альфе первого кадра включения.

- Включение монотонно по суммарной альфе; последний кадр равен первому кадру цикла.
- Все 142109 непрозрачных пикселей букв и непрозрачный силуэт постоянны во всех
  750 кадрах цикла; заданные лицевые RGB присутствуют.
- Контрольные кадры совпадают с согласованными превью B.
- Кадр 1 совпадает с пробным виртуальным кадром 751. Кадр 751 не экспортировался.
- На переходе 750 → 1 максимальное изменение исходного RGBA — **1/255**.
- На имитации графита максимальный шаг на стыке — **1.522/255** по RGB,
  средний — 0.002668/255. Это не выброс относительно соседних переходов.
- Проверены все **750 соседних переходов с учётом стыка**: максимум
  **1.734/255** по RGB на графите и **1/255** по альфе.
- Корреляция средней альфы ореола с заданной медленной синусоидой — **0.9999978**.

Точные значения — `export_checks.json`; SHA-256 всех PNG — `png_sha256.json`.
`audit_scene.py` подтвердил две сцены, частоту/размер, упакованный шрифт,
неподвижную камеру, монотонное включение и периодическую формулу на 751 позиции.

## Проверка движком Shotcut

Штатные `qimage` и `qtblend` установленного Shotcut/MLT выполнили отдельную
композицию `checks/loop_twice.mlt`: два полных цикла на имитации графита `#171C20`,
683 × 239, 25 FPS. Исходный проект не открывался.

Результат `checks/loop_twice_graphite.mkv` (FFV1) полностью декодирован:
**1500 кадров, 60 секунд**. Все 750 кадров второго повтора покадрово совпадают
с первым. Шаг на стыке и максимум внутри видео — **2/255** по RGB после
масштабирования и композитинга QImage. Наложение альфы сохраняет свечение;
фон диагностического видео имеет ожидаемый цвет, чёрной подложки нет.
Кадр и соседние состояния стыка также просмотрены как изображения.

Подробности — `checks/mlt_checks.json`. Диагностическое MKV непрозрачно и
не предназначено для наложения; основной результат — PNG RGBA.

## Команды, выполненные из корня репозитория

```bash
media/sinegor-led/run_blender.sh --mode final --approved-final --preset B \
  --out media/sinegor-led/output/final_B
python3 media/sinegor-led/verify_export.py --out media/sinegor-led/output/final_B
python3 -m unittest discover -s media/sinegor-led -p 'test_*.py'
apps/api/.venv/bin/ruff check media/sinegor-led
bash -n media/sinegor-led/run_blender.sh
python3 -m compileall -q media/sinegor-led
```

Все 12 unit-тестов, Ruff, синтаксис shell и компиляция Python прошли.
Новые проверки отдельно воспроизвели отсутствие валидатора, пропуски/хвост,
потерю альфы и возможность пропустить RGB-вспышку внутри цикла; после реализации
и корректировки проверки прошли. Независимое ревью выявило пробел в контроле
промежуточных шагов; он исправлен проверкой всех соседних переходов.

Повторная проверка сохранённого .blend:

```bash
SINEGOR_LED_DIR="$PWD/media/sinegor-led"
flatpak run "--env=OCIO=$SINEGOR_LED_DIR/srgb.ocio" org.blender.Blender \
  -b "$SINEGOR_LED_DIR/output/final_B/SINEGOR_LAB.blend" \
  --python-exit-code 1 --python "$SINEGOR_LED_DIR/audit_scene.py"
```

Повтор теста через движок Shotcut/MLT (создаёт непрозрачную диагностическую копию):

```bash
SINEGOR_CHECK_DIR="$PWD/media/sinegor-led/output/final_B/checks"
flatpak run --env=QT_QPA_PLATFORM=offscreen --command=melt org.shotcut.Shotcut \
  "$SINEGOR_CHECK_DIR/loop_twice.mlt" \
  -consumer "avformat:$SINEGOR_CHECK_DIR/loop_twice_graphite_copy.mkv" \
  vcodec=ffv1 level=3 pix_fmt=bgra an=1 real_time=-1 threads=1 f=matroska
```

## Изменения и ограничения

Добавлены `verify_export.py`, `test_final_export.py`, финальные файлы и отчёты;
обновлён основной `media/sinegor-led/README.md`. Генератор, пресеты B, шрифт и OCIO
после согласования не менялись. Контроль SHA-256 прежних артефактов прошёл.
Git staging, коммиты и операции изменения Git не выполнялись.

Проверка Shotcut выполнена **вне GUI через его движок**, а не просмотром
пользовательского проекта. Использована однородная имитация таблички;
реальная табличка и движущееся исходное видео в этой проверке не использовались.
Окончательная оценка на исходном видео остаётся за пользователем при импорте.
Альфа-видео дополнительно не создавалось.

При повторном полном рендере используйте новую пустую папку: генератор не удаляет
старый хвост последовательности. `verify_export.py` такой хвост отвергает.
